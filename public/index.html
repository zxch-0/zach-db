    05 API serveur (curl)
    
    

    # la liste des sites, avec leurs compteurs
curl -X POST --data-binary @fichier.txt 'https://VOTRE-APP.onrender.com/api/group'
curl -X POST --data-binary @fichier.txt 'https://VOTRE-APP.onrender.com/api/group?format=tsv'

# toutes les valeurs d'un seul site, écrites au fil de l'eau
curl -X POST --data-binary @fichier.txt \
  'https://VOTRE-APP.onrender.com/api/group?site=roblox.com' -o roblox.txt

# extraction simple, sans tri par site
curl -X POST --data-binary @fichier.txt \
  'https://VOTRE-APP.onrender.com/api/extract?mode=last&dedupe=1' -o resultat.txt
    
      
    Paramètres : mode, regex, dedupe=1,
        hosts=1, subdomains=0, site, format
        (json, tsv, txt, ndjson), dir,
        paths=1. La réponse est diffusée en flux : un fichier de plusieurs Go ne passe
        jamais entièrement en mémoire.
    
    
    
  
    

  
    
    06 Ligne de commande
    
    

    node cli.js gros.txt --group                       # site + compteurs
node cli.js gros.txt --group --json                # la même en JSON
node cli.js gros.txt --group --site=roblox.com -o roblox.txt
node cli.js gros.txt --group --split=dossier/      # un .txt par site

node cli.js gros.txt -o resultat.txt --mode=last --dedupe
zcat gros.txt.gz | node cli.js --mode=last > resultat.txt
    
      
    Mémoire constante, .gz accepté, --keep-hosts pour
        garder domaine.tld:port, --exact pour ne pas regrouper les
        sous-domaines.
    
    
    
  
    

  
    
    07 Comment un site est reconnu
    
    
      
      
        
    • l'hôte est lu sur la ligne : https://, http://, //
          ou directement roblox.com/login ; ports, IP et user:pass@hote
          sont gérés ;
      • 
        
    • roblox.co.uk reste distinct de roblox.com ;
      • 
        
    • une ligne sans URL va dans le groupe (sans site) ;
      • 
        
    • les lignes sans couple xxxx:xxxx sont comptées comme « ignorées » ;
      • 
        
    • un couple est une suite de segments séparés par : ne contenant que lettres,
          chiffres, . _ @ + -.
