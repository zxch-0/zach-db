02Common ground

Every tool here obeys the same three rules.

Local first

The file is streamed in a Web Worker, line by line: the page stays responsive and no byte goes over the network. The server API and the CLI exist for files too big for a browser tab, not by default.

One engine, three ways in

The same parsing code runs in the browser, behind /api/… and in cli.js. One behaviour, three entry points — so a result is reproducible wherever you got it.

Zero dependency

No framework, no build step, no external font or image: plain HTML, CSS and modules. Black and white, no emoji, and every animation stops when your system asks for less movement.
