    API serveur (curl) — liste des sites ou un seul site

    # la liste des sites, avec compteurs
curl -X POST --data-binary @fichier.txt 'https://VOTRE-APP.onrender.com/api/group' 
curl -X POST --data-binary @fichier.txt 'https://VOTRE-APP.onrender.com/api/group?format=tsv'

# toutes les valeurs d'un site
curl -X POST --data-binary @fichier.txt \
  'https://VOTRE-APP.onrender.com/api/group?site=roblox.com' -o roblox.txt
    
  
    

  
    
    CLI : liste, un site, ou un fichier par site

    node cli.js gros.txt --group                       # site + compteurs
node cli.js gros.txt --group --site=roblox.com -o roblox.txt
node cli.js gros.txt --group --split=dossier/      # un .txt par site
