guns.lol deduplicates views by IP and by day, so volume needs addresses. The server harvests the public proxy lists, triages them with a real CONNECT + TLS test against guns.lol, then replays what a browser does on a profile — the page, the analytics pixel, the view endpoint and the signed analytics event — one attempt per proxy.
