Every account,
read from its ID.

A Discord user ID is a snowflake: 42 bits of timestamp, 5 of worker, 5 of process, 12 of increment. Decode it and you already know when the account was created — no network, no token. Add a bot token on the server and the rest follows: names, badges, avatar, banner, accent colour, assets, and the servers you have in common.

      Bot tokenthe only thing between you and the full profile
      
      
        
      Create a bot, then give the token to the server
      

      # 1. https://discord.com/developers/applications → New application
# 2. Bot → Reset token → copy it (no privilege, no intent needed)
# 3. give it to the server, never to the browser:
DISCORD_TOKEN=your-bot-token
DISCORD_GUILD_CAP=40        # servers checked when ?guilds=1
DISCORD_RATE_MAX=30         # lookups per address per minute
DISCORD_TIMEOUT_MS=8000
      
      
      
      
      
        
      Without a token
      

      # the tool still answers: everything a snowflake carries
curl 'https://YOUR-APP.onrender.com/api/discord/user?id=175928847299117063'
# → { "mode": "offline", "snowflake": { "created", "worker", "increment" … } }
